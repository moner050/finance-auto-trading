유니버스는 개별 종목의 모음이 아니라 특정 날짜의 발표된 목록 하나입니다. 그래서 이 화면에는 종목을 한 개 추가하는 방법이 없습니다 — 손으로 넣은 종목은 아무도 발표하지 않은 유니버스를 만듭니다. 올리는 단위는 매니페스트 전체입니다.

이 화면을 쓰는 법

순서

  1. 발표된 목록을 아래 형식의 JSON 매니페스트 파일로 만듭니다. 기관이 발표한 그대로여야 하고, 여기서 손으로 고친 목록은 출처가 없는 목록입니다.
  2. 스테이징. 형식·중복·개수를 검사한 뒤 저장합니다. 스테이징은 아무것도 사용되게 만들지 않으므로 2차 비밀번호를 묻지 않습니다. 잘못 올렸으면 활성화하지 않고 두면 됩니다.
  3. 아래 활성 대비 변경에서 추가·제외·재분류를 확인합니다. 종목 수만 보면 하나가 다른 하나로 바뀐 것을 볼 수 없습니다.
  4. 승인. 2차 비밀번호를 입력합니다. 승인은 확인 화면에 보인 그 다이제스트에 묶이므로, 세 종목 바뀌는 것을 승인한 사람이 서른 종목 바뀌는 활성화에 그 승인을 쓸 수 없습니다. 60초 후 만료되고 한 번만 쓰입니다.
  5. 활성화. 다음 평가부터 적용되고, 직전 목록은 지워지지 않고 supersede 됩니다. "그 거래를 결정한 날 이 종목이 목록에 있었는가"는 답이 있는 질문이고, 덮어쓰는 순간 답이 사라집니다.

매니페스트 형식

  • universe_code — KOSPI200, SP100, BINANCE_USDM 중 하나. 그 외의 값은 거부됩니다.
  • effective_date — 이 목록이 사실인 날짜 (YYYY-MM-DD). 올린 날짜가 아니라 목록의 기준일입니다.
  • source — name(64자), reference(255자), published_at(오프셋이 붙은 시각, 예 2026-09-01T18:00:00+09:00). 출처는 기록되고 감사되지만 다이제스트에는 들어가지 않습니다.
  • members — 1개 이상 5000개 이하, 같은 symbol(32자)이 두 번 나오면 거부됩니다.
  • common_stock — KOSPI200·SP100 에서는 필수이고 정확히 true 또는 false 여야 합니다. BINANCE_USDM 에서는 무기한 선물이 주식 클래스가 아니므로 넣으면 거부됩니다.
  • sector — 선택(64자). 빠져도 업로드는 통과하지만, 그 종목은 판단에서 SECTOR_AUTHORITY_UNAVAILABLE 로 막힙니다. 거부하지 않는 이유는 그 편이 더 정확한 사실을 남기기 때문입니다.
  • 파일은 1MB 이하여야 합니다.
{
  "universe_code": "KOSPI200",
  "effective_date": "2026-09-01",
  "source": {
    "name": "KRX",
    "reference": "https://data.krx.co.kr/... (2026-09-01)",
    "published_at": "2026-09-01T18:00:00+09:00"
  },
  "members": [
    { "symbol": "005930", "common_stock": true, "sector": "it" },
    { "symbol": "005935", "common_stock": false, "sector": "it" },
    { "symbol": "000660", "common_stock": true, "sector": "it" }
  ]
}

다이제스트

업로드 칸의 다이제스트는 파일의 sha256 이 아닙니다. universe_code · effective_date · members 만 심볼 순으로 정렬한 정규형의 sha256 입니다. 그래서 같은 목록을 다른 곳에서 받아 들여쓰기와 순서가 달라도 같은 값이 나오고, 종목이 하나만 달라도 반드시 다른 값이 나옵니다. 발표자가 같은 규칙으로 계산한 값을 주지 않았다면 비워두십시오 — 파일 해시를 넣으면 맞는 파일이 거부됩니다.

아래 표의 다이제스트는 앞 16자리만 보여줍니다. 두 스냅샷이 같은 목록인지 확인하는 데는 충분하고, 전체 값이 필요하면 감사 기록에 남아 있습니다.

활성화하면 무엇이 달라지는가

KOSPI200 · SP100 — 현금 주식 판단의 첫 관문입니다. 목록에 없으면 NOT_MEMBER_AS_OF, 보통주가 아니면 NOT_COMMON_STOCK_AS_OF 로 신규 진입이 막힙니다.

BINANCE_USDM — 지금 돌고 있는 무기한 선물 루프는 이 목록으로 걸러지지 않습니다. 엔진이 선물 시장의 유니버스 증거를 UNIVERSE_CASH_ONLY(해당 없음)로 처리하기 때문입니다. 올려두면 기록으로는 유효하지만, 활성화해도 루프가 무엇을 거래하는지는 달라지지 않습니다.

자주 나오는 거부

  • is not a known universe — universe_code 오타.
  • appears twice — 같은 심볼이 두 줄.
  • needs an exact common_stock flag — 주식 유니버스인데 플래그가 없거나 true/false 가 아님.
  • is not a share class — BINANCE_USDM 에 common_stock 을 넣음.
  • does not match the claimed digest — 넣은 다이제스트와 계산한 값이 다름. 위의 다이제스트 설명을 보십시오.
  • a universe with no members filters nothing — members 가 비어 있음.
